Simulador de Asistente WhatsApp

Prueba el flujo automatizado para la evaluación de devoluciones. Este bot guiará al ejecutivo recopilando los datos requeridos por el protocolo IAsapre y validará las respuestas automáticamente.

Reglas de Evaluación Automática

  • Contacto en menos de 24h obligatorio.
  • Falta de anualidad: Si permanencia ≥ 10 meses = RECHAZO.
  • Máximo 5 devoluciones por bolsa.
  • Wsp Inexistente: Se reemplaza y no descuenta cupo.
  • Comprobantes y mensaje de cierre obligatorios.

Guía de Integración WhatsApp API

Cómo llevar este simulador a un número real para que tus ejecutivos lo usen.

1. Arquitectura Recomendada

Para implementar este sistema en un entorno de producción, recomendamos la siguiente arquitectura:

  • Proveedor WhatsApp: Meta Cloud API (oficial) o Evolution API (para números de WhatsApp sin verificar).
  • Plataforma de Flujos: ManyChat, Chatwoot, o Typebot para diseñar el árbol de decisiones visualmente.
  • Backend de Validación: Un servidor Webhook en Node.js (Express) que reciba los datos recolectados, ejecute la lógica de negocio y guarde el resultado en tu base de datos o Google Sheets.

2. Código Central del Webhook (Node.js)

Este es el código que debes implementar en tu servidor (ej. usando Render, Heroku o AWS) para evaluar automáticamente las devoluciones que lleguen desde el bot real.


const express = require('express');
const app = express();
app.use(express.json());

app.post('/webhook/devoluciones', (req, res) => {
    const { 
        ejecutivo, bolsa, causal, mesesPermanencia, 
        horasDesdeAsignacion, adjuntos 
    } = req.body;

    let estado = "APROBADA";
    let motivo = "Cumple criterios del protocolo IAsapre.";

    // Regla 1: Contacto dentro de 24 hrs
    if (horasDesdeAsignacion > 24) {
        estado = "RECHAZADA";
        motivo = "El contacto superó las 24 horas reglamentarias.";
    } 
    // Regla 2: Falta de anualidad
    else if (causal === "Falta de anualidad" && mesesPermanencia >= 10) {
        estado = "RECHAZADA";
        motivo = "La permanencia es de 10 meses o más. Máximo permitido: 9 meses.";
    }
    // Regla 3: WhatsApp Inexistente
    else if (causal === "Whatsapp Invalido") {
        estado = "REEMPLAZO";
        motivo = "El dato se reemplazará y no consumirá cupo de la bolsa.";
    }
    // Añadir validaciones de adjuntos, límite de 5 devoluciones por bolsa por ejecutivo, etc.
    
    // Responder a la API de WhatsApp/ManyChat para notificar al ejecutivo
    res.json({
        success: true,
        veredicto: estado,
        mensaje_ejecutivo: `Su solicitud ha sido ${estado}. Motivo: ${motivo}`
    });
});

app.listen(3000, () => console.log('Servidor corriendo en puerto 3000'));
